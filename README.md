# LMS Library Mangement System

LMS is a two week hands-on project to have understanding on Software project Management, 
Git, Github, Docker, Database, Testing and FASTAPI.

## Tech Stack

ClickUP for Software Project Management
Github for Version Control
Docker for Containerization
PostgreSQL for Database
FASTAPI for API Development

## Features

Book Management
- Add Books
- Remove Books
- Search Books
- List Books

Member Management
- Register Member
- View Members

Loan Management
- Issue Book
- Validate Book Availability
- Return Book
